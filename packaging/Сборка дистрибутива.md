# Сборка дистрибутива

Обе версии собираются в Docker и складываются в `Application/dist/`. Для каждой ОС получается папка и архив:

| ОС | Архив | Размер | Где работает |
|---|---|---|---|
| Linux | `biosignal-analyzer-1.0-linux-x86_64.tar.xz` | 22 МБ (в распакованном виде 84 МБ) | glibc 2.35 и новее: Ubuntu 22.04+, Debian 12+, Fedora 36+, Arch |
| Windows | `biosignal-analyzer-1.0-windows-x86_64.zip` | 13 МБ (в распакованном виде 31 МБ) | Windows 10 и 11, 64 бит |

Python с библиотеками в архив не входит — его ставит пользователь (см. ниже).

## Что нужно

- Docker: служба запущена, пользователь в группе `docker`.
- `uv`: через него запускается aqtinstall, который скачивает Qt.
- Сеть при первой сборке.
- wine — только чтобы проверить Windows-версию.

## Сборка

Команды запускаются из папки `Application`.

```
packaging/build-linux.sh
packaging/build-windows.sh
```

Первый запуск сам скачивает недостающее:
- **образ** `biosignal-build:22.04`, около 0,6 ГБ — собирается по `packaging/Dockerfile`. Собрать его отдельно: `docker build -t biosignal-build:22.04 packaging`.
- **Qt 6.8.3** в `build/qt`, около 0,6 ГБ — через aqtinstall: готовые библиотеки, без компиляции.

После этого каждая сборка занимает около полутора минут.

## Как устроено

- **Linux.** Программа собирается в Ubuntu 22.04, поэтому архив работает на всех системах с glibc не старше, чем в ней.
  - linuxdeploy копирует рядом с программой Qt, его модули и библиотеки, которых на рабочем столе может не быть (xcb-util, xcb-cursor).
  - Модуль печати Qt удаляется: программа не печатает, а он тянет за собой libcups.
  - Программа берёт libGL системы (`OpenGL_GL_PREFERENCE=LEGACY`). Иначе она требовала бы libopengl0, которой во многих системах нет.
  - Запуск: `./biosignal-analyzer`.
- **Windows.** Программа кросс-компилируется llvm-mingw 17.0.6 с Qt 6.8.3 из комплекта `win64_llvm_mingw` (UCRT и libc++).
  - Комплект Qt на MinGW GCC не подходит: он собран под старую `msvcrt.dll`, а нынешние MinGW собирают под UCRT.
  - В папку кладутся программа, модули Qt (окна, стиль, форматы изображений, значки SVG) и все DLL, которые они берут из Qt и llvm-mingw.
  - Запуск: `biosignal_analyzer.exe`.
- **Версии инструментов** — в `packaging/common.sh` и `packaging/Dockerfile`. linuxdeploy берётся из непрерывных выпусков: в образе сейчас сборка 373 от 01.11.2026. При пересборке образа может прийти более новая.

## Установка у пользователя

1. Распаковать архив.
2. Для обучения и распознавания поставить Python 3.10 или новее с NumPy, SciPy и PyTorch. Удобнее всего — окружение `.venv` рядом с исполняемым файлом. Без Python работают все страницы, кроме обучения и распознавания; при их запуске программа сообщает, чего не хватает.

**Linux** (рядом с исполняемым файлом — это папка `bin`):

```
cd biosignal-analyzer-1.0-linux-x86_64/bin
python3 -m venv .venv
.venv/bin/pip install numpy scipy
.venv/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu
```

**Windows** (в командной строке):

```
cd biosignal-analyzer-1.0-windows-x86_64
py -m venv .venv
.venv\Scripts\pip install numpy scipy
.venv\Scripts\pip install torch --index-url https://download.pytorch.org/whl/cpu
```

Индекс `…/whl/cpu` ставит PyTorch без поддержки видеокарты, около 1 ГБ. Для видеокарты NVIDIA вместо него указывают индекс с CUDA, например `https://download.pytorch.org/whl/cu126` (версия — по pytorch.org); вместе с ним ставится ещё около 4–5 ГБ.

Если `.venv` рядом с программой нет, она берёт Python из системы:
- Linux — `python3`;
- Windows — `py -3`, а без него `python`.

Тогда библиотеки ставятся в этот Python.
