## EEG/ЭКГ ADC — протокол прикладного уровня (поверх SerProt v0.2)

### Общие положения

Прикладной уровень работает поверх транспортного протокола **SerProt v0.2**. Все прикладные сообщения передаются в поле `payload` транспортных фреймов.

Структура `payload` для команд:

```
payload = [cmd_id] [params...]
```

- `cmd_id` — 1 байт, идентификатор команды
- `params` — 0 или более байт параметров (зависит от команды)

Ответные пакеты (`0xDD` Response / `0xEE` Error) имеют `payload`, определяемый результатом выполнения команды. По умолчанию успешный ответ имеет пустой payload.

---

### Таблица команд

| Код | Команда | Направление | Описание |
|---|---|---|---|
| `0x01` | StartStream | Master → Slave | Запуск стриминга АЦП с указанием активных каналов |
| `0x02` | StopStream | Master → Slave | Остановка стриминга |
| `0x10` | SetVref | Master → Slave | Внутренняя опора 2,4 В (фиксированная, без настройки) |
| `0x11` | SetSamplerate | Master → Slave | Установка частоты дискретизации |
| `0x20` | GetDeviceInfo | Master → Slave | Запрос информации об устройстве (id, версия, каналы, описание) |
| `0x30` | SetGain | Master → Slave | PGA канала ADS1298 (`[channel][gain_code]`) |
| `0x31` | InputShort | Master → Slave | Внутреннее замыкание входов всех каналов |
| `0x32` | TestSignal | Master → Slave | Внутренний меандр на всех каналах (`[amplitude][frequency]`) |
| `0x33` | NormalInput | Master → Slave | Обычный вход всех каналов; отключение тестового режима |


---

### 0x01 — StartStream

Запускает непрерывную отправку Push-пакетов с данными АЦП.

**Payload запроса:**

```
[cmd_id=0x01] [N] [ch_0] [ch_1] ... [ch_N-1]
```

| Поле | Размер | Описание |
|---|---|---|
| `cmd_id` | 1 B | `0x01` |
| `N` | 1 B | Количество активных каналов (1–8) |
| `ch_i` | 1 B | Индекс физического канала АЦП (0–7) |

**Требования:**
- Список каналов `ch_i` должен быть отсортирован по возрастанию.
- Все индексы каналов должны быть уникальны.
- `N` не может быть 0.

**Payload ответа (Response):** пустой.

**Возможные ошибки:**
- `0x02` — неверные параметры (неверное количество каналов, дубли, выход за 0–7)
- `0x03` — устройство не готово (АЦП не инициализирован)
- `0x06` — неверный размер payload

---

### 0x02 — StopStream

Останавливает стриминг АЦП. Slave прекращает отправку Push-пакетов.

**Payload запроса:**

```
[cmd_id=0x02]
```

**Payload ответа (Response):** пустой.

**Примечание:** Если стриминг уже остановлен, команда считается успешной.

---

### 0x10 — SetVref

Историческая команда установки внешней опоры. В ADS1298 используется встроенная
опора 2,4 В, поэтому параметры команды игнорируются, а при корректном формате
возвращается пустой успешный Response.

**Payload запроса:**

```
[cmd_id=0x10] [mV_L] [mV_H]
```

| Поле | Размер | Описание |
|---|---|---|
| `cmd_id` | 1 B | `0x10` |
| `mV_L` | 1 B | Младший байт напряжения (мВ) |
| `mV_H` | 1 B | Старший байт напряжения (мВ) |

**Диапазон:** 0–3300 мВ.

**Формат:** `Vref_mV = mV_L | (mV_H << 8)`

**Payload ответа (Response):** пустой.

**Возможные ошибки:**
- `0x06` — неверный размер payload

---

### 0x11 — SetSamplerate

Устанавливает частоту дискретизации АЦП.

**Payload запроса:**

```
[cmd_id=0x11] [idx]
```

| Поле | Размер | Описание |
|---|---|---|
| `cmd_id` | 1 B | `0x11` |
| `idx` | 1 B | Индекс частоты дискретизации |

**Таблица частот:**

| `idx` | Частота (Гц) |
|---|---|
| `0x00` | 250 |
| `0x01` | 500 |
| `0x02` | 1000 |
| `0x03` | 4000 |
| `0x04` | 2000 |

**Payload ответа (Response):** пустой.

**Возможные ошибки:**
- `0x02` — неверные параметры (`idx` вне 0x00–0x04)

> Стриминг должен быть остановлен перед сменой частоты. Рекомендуемая последовательность: StopStream → SetSamplerate → StartStream.

### 0x30/0x31/0x32/0x33 — Режимы входов и усиление ADS1298

`SetGain (0x30)`: `[0x30] [channel 0..7] [gain_code 0..6]`, где коды PGA
соответствуют 6, 1, 2, 3, 4, 8 и 12 V/V.

`InputShort (0x31)`: `[0x31]`; включает штатный внутренний input-short
ADS1298 (MUX=001) на всех каналах. Оба входа каждого канала подключаются
к внутреннему общему уровню `(AVDD + AVSS) / 2` для измерения смещения и
шума; это не подключение контактов платы непосредственно к GND.

`TestSignal (0x32)`: `[0x32] [amplitude 0/1] [frequency 0/1]`.
Включает `CONFIG2.INT_TEST=1` и маршрутизирует тестовый сигнал (MUX=101)
на все каналы. Коды частоты соответствуют ADS1298: `0` — `fCLK/2^21`,
`1` — `fCLK/2^20`. Оба варианта являются меандром; постоянный уровень
(`TEST_FREQ=3`) намеренно не предоставляется прикладным протоколом.
`amplitude=0` выбирает 1× `(VREFP - VREFN) / 2400`, `amplitude=1` — 2×
(при внутренней опоре 2,4 В это примерно 1 мВ и 2 мВ соответственно).
Используется только внутренний генератор ADS1298, внешний тестовый источник
не рассматривается.

`NormalInput (0x33)`: `[0x33]`; отключает `CONFIG2.INT_TEST` и возвращает
все каналы к обычному электродному входу (MUX=000).

Режимы переключают все восемь каналов одновременно и не принимаются во
время активного стриминга. Для переключения используйте последовательность
`StopStream → команда режима → StartStream`.

Опорное напряжение ADS1298 фиксировано внутренним 2,4 В. `SetVref (0x10)`
сохраняется как совместимостная заглушка и всегда отвечает успешным Response.

### 0x20 — GetDeviceInfo

Возвращает идентификацию устройства. Программа использует эту команду при
сканировании портов: если устройство корректно отвечает на транспортном и
прикладном уровне, оно попадает в список доступных устройств на странице Devices.

**Payload запроса:**

```
[cmd_id=0x20]
```

**Payload ответа (Response):**

```
[device_id_L] [device_id_H] [fw_major] [fw_minor] [n_channels] [desc_len] [desc...]
```

| Поле | Размер | Описание |
|---|---|---|
| `device_id` | 2 B | Идентификатор типа устройства (little-endian). Определяет назначение устройства |
| `fw_major` | 1 B | Мажорная версия прошивки |
| `fw_minor` | 1 B | Минорная версия прошивки |
| `n_channels` | 1 B | Количество физических каналов АЦП (может быть 0 для устройств без каналов) |
| `desc_len` | 1 B | Длина строки описания в байтах (0–249) |
| `desc` | `desc_len` B | UTF-8 строка с человекочитаемым описанием |

**Идентификаторы устройств (`device_id`):**

| ID | Устройство |
|---|---|
| `0x0001` | ЭКГ/ЭЭГ/ЭМГ АЦП front-end (8 каналов) |

> Список пополняется по мере добавления новых устройств. Устройство, чей
> `device_id` неизвестен программе, всё равно отображается — с общим описанием.

**Пример ответа** (device_id=1, fw 1.0, 8 каналов, описание "ADS1298 EEG/ECG"):

```
0x01 0x00 0x01 0x00 0x08 0x0F 'A' 'D' 'S' '1' '2' '9' '8' ' ' 'E' 'E' 'G' '/' 'E' 'C' 'G'
```

### Push-пакеты с данными АЦП

Push-пакеты имеют тип `0xFF` на транспортном уровне и отправляются непрерывно во время активного стриминга.

**Payload Push-пакета:**

```
[sample_ch0] [sample_ch1] ... [sample_chN-1]
```

- Каждый сэмпл канала — 3 байта (24-bit signed integer, little-endian, two's complement).
- Каждый Push содержит ровно одну выборку ADS1298: по одному отсчёту каждого
  выбранного канала.
- Отсчёты упакованы в порядке активных каналов, переданных в `StartStream`.
- Следующий Push содержит следующую выборку; накопления нескольких выборок в
  одном пакете нет.

**Формат одного сэмпла:**

```
[byte_0] [byte_1] [byte_2]
```

`raw = byte_0 | (byte_1 << 8) | (byte_2 << 16)`

Если `raw >= 0x800000`, то `raw -= 0x1000000` (знаковое 24-битное значение).

**Единицы измерения:**

MCU отправляет значения в **микровольтах (µV)**. Для перевода raw-кода в вольты:

```
V = raw * 1e-6   // результат в вольтах
```

**Размер payload:**

Размер Push-payload всегда равен `N * 3` байт, где `N` — количество активных
каналов (одна выборка, 3 байта на канал). Для ADS1298 при `N=1..8` это 3..24
байта; размер не настраивается отдельной командой.

### Примеры

#### Запуск стриминга каналов 0 и 2

```
Command payload:  0x01  0x02  0x00  0x02
                    │    │     │     └─ канал 2
                    │    │     └─ канал 0
                    │    └─ количество каналов: 2
                    └─ StartStream
```

#### Установка Vref = 1000 мВ

```
1000 = 0x03E8
Command payload:  0x10  0xE8  0x03
                    │    │     └─ mV_H
                    │    └─ mV_L
                    └─ SetVref
```

#### Установка частоты 1 кГц

```
Command payload:  0x11  0x02
                    │    └─ idx = 2
                    └─ SetSamplerate
```

#### Переключение режимов входов

Команды режимов действуют сразу на все восемь каналов и принимаются только
при остановленном стриминге:

```
0x31                         InputShort: внутренний input-short ADS1298
0x32 0x01 0x00                TestSignal: амплитуда 1, fCLK/2^21
0x33                         NormalInput: обычные электродные входы
```

При смене режима во время работы сначала отправьте `StopStream`, затем одну
из команд выше и снова `StartStream`. `InputShort` замыкает входы внутри
ADS1298 на общий уровень (AVDD + AVSS) / 2 для измерения смещения и шума;
это не подключение контактов платы непосредственно к GND.

#### Push-пакет с 1 сэмплом 2 каналов

```
Payload:  0x10  0x27  0x00  │  0x20  0x4E  0x00
             канал 0 = 10000 µV  │  канал 2 = 20000 µV
```

---

### Ответы и ошибки

**Response (0xDD):**

- По умолчанию payload пустой.
- `seq` совпадает с `seq` вызвавшей команды.

**Error (0xEE):**

Payload содержит 1 байт — код ошибки (см. `Protocol_Specifiaction.md`).

Наиболее частые ошибки прикладного уровня:

| Код | Значение |
|---|---|
| `0x01` | Неизвестная команда |
| `0x02` | Неверные параметры |
| `0x03` | Устройство не готово |
| `0x06` | Неверный размер payload |

---

### Рекомендуемые последовательности

#### Инициализация после подключения

1. Подключиться по UART.
2. `SetVref(2400 мВ)` — совместимостная команда (внутренняя опора фиксирована).
3. `SetSamplerate(0)` — установить 250 Гц.
4. `StartStream([0])` — начать стриминг канала 0.

#### Смена частоты дискретизации

1. `StopStream()`
2. `SetSamplerate(idx)`
3. `StartStream(active_channels)`

#### Смена активных каналов

1. `StopStream()`
2. `StartStream(new_active_channels)`
